# A rope end changes the machine

An English-speaking learner should discover the constraint of Vitruvius X.2.1–3,
then read the words responsible for it. The distinctive action is moving the tied
end while retaining every wheel, rather than selecting a mechanical-advantage
number. Force, travel and work must agree with that actual route.

The frontend-design skill was read before this plan and UI work. The existing
Gonia typography remains the family resemblance. The workshop uses cool drawing
paper (#eef3f5), graphite (#233341), rope blue (#315f81), moving-load violet
(#635483), white (#ffffff) and muted slate (#52616c). Plex labels motion and
measurements; Noto carries Latin and Greek. Colour also has shape/text labels.

The rope occupies the first substantial view. A quiet explanatory column sits
beside it on desktop and beneath it on phones. Controls retain stable DOM nodes.
The winding drum is a separate circular detail; it is not drawn to the same
scale as the unrolled block diagram. No invented timber-frame restoration.

    native reading + diagram + CSV + strict editable state

A generic antique-paper treatment would repeat other rooms without explaining
this machine. The revised plan instead uses the physical rope route as its
organising structure. Borders indicate the fixed support, moving assembly and
separate windlass only. No autoplay or decorative motion. The slider itself
operates the load, and reversing its direction unwinds it.

Review must include the tied-end counterexample, fixed rope take-up versus fixed
rise, the windlass force/path exchange, actual native files, complete printed
source pages, keyboard/mobile use and an eight-to-nine-room offline upgrade.
