# Reading the space between columns

The addition is a second Gonia workshop, based on Vitruvius III.3. It explains
the five spacing names, the diameter used as a module, and why the eustyle
centre gap differs from its neighbours. It does not assign generic proportions
to a surviving temple or treat Vitruvius's judgments as structural calculations.

## Design

Retain Gonia's existing palette and typography: paper `#f4f1e8`, ink `#27352f`,
green `#405a43`, muted text `#5f6559`, rules `#bfc3b3`, and the existing
dimension accent `#963b25`. Plex carries controls and measurements; Noto Serif
carries the Latin and Greek. The addition should feel like another working
drawing in the same architectural notebook.

```text
Spacing name and short explanation
Five choices: close / joined / well-spaced / open / widely separated

Column count + what stays fixed       Latin instruction
                                     + new English translation
          measured front elevation
          measured plan of the same row

Diameter, gap, height, front width    Read the Greek word-parts
Comparison of all five choices       Inspect the printed source
```

The drawing is the main experience. Avoid a separate decorative hero, stock
temple illustration, or five identical information cards. A stable drawing
scale makes a spacing change visible; a fixed-width comparison and a
fixed-diameter comparison answer different questions. The plan distinguishes
the clear gap from the axis spacing. Mobile retains legible dimensions instead
of shrinking a desktop plate's text.

The eustyle counterexample is an explicit user alteration: make every gap
2.25 diameters, then inspect the lost 0.75-diameter centre allowance. The
download and shared link must retain that altered status. The araeostyle gap
is also explicitly a chosen example, since III.3.5 supplies no numerical gap.

## Source decisions

Krohn (1912), printed pp. 64–67, was inspected directly. III.3.7 and III.3.10
give eustyle height as nine and a half diameters. The latter spells it out as
`novem ... et dimidiam partem`; Gwilt's English rendering of eight and a half
is not used as the numerical source. Krohn's printed Roman numerals and
critical apparatus remain visible in the scans. The width modules are 11.5,
18 and 24.5 for four, six and eight columns, excluding base projections.

The model follows equal lower-shaft diameters before the later corner-thickening
adjustment. It does not model entasis, taper rules, bases, capital geometry,
entablature loads or the complete plan of a named temple. The silhouette is
illustrative. Metres are a modern scale choice, not a conversion from Roman feet.
