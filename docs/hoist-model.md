## What is modelled

X.2.1 ends the reeving at the lower block. Under parallel-strand idealisation,
that tied end supplies one upward tension, in addition to the two supplied
by each moving wheel. Thus the three-wheel source route has three supports;
the five-wheel continuation has five. Tying that end to the fixed support is
our modern alteration: it keeps the wheels and removes the tied-end tension
from the moving assembly. A single fixed wheel is a modern control.

The source locates wheels vertically within each block. The drawing spreads
them horizontally and expands that axis to expose the rope. It is a topological
and vertical-travel schematic, not an equal-scale restoration. The load outline
and wheel diameters do not describe a measured ancient object.

The route is explicit: alternating vertical lines and half-circle arcs. A
moving tie begins at the lower axle height. A fixed tie begins 0.5 m beneath
the upper axle. Each lower-wheel run shortens with the rise, and its arc keeps
the same length. The final run to the drum is fixed. The number of marked
supporting lines is counted from this route, rather than looked up by the
wheel name. Rope take-up is computed as initial minus current route length.
White dots mark fixed material distances from the tied end; dots beyond the
visible route are wound onto the drum. Changing rig or tie establishes a new
rope reference; it is not an animation of re-reeving an existing taut machine.

With n supporting portions, rise h, take-up s, weight W and equal tension T:
`s = n h`, `n T = W`. The chosen drum radius is R = 0.15 m and arm L is
0.15, 0.30 or 0.60 m. Perpendicular hand force F obeys `F L = T R`, and hand
path is `(L/R)s`. Therefore `W h = T s = F × hand path`. The diagram's drum
turns in the direction consistent with incoming rope at its right tangent.
The displayed values are rounded; exported rows retain full floating values.

Holding rise fixed compares the same lifting task. Holding take-up fixed
changes the attained height and therefore work. Neither comparison converts
wheel count into an unexplained efficiency score.

The modern ideal analysis can be compared with
[OpenStax, College Physics 2e, 9.5 Simple Machines](https://openstax.org/books/college-physics-2e/pages/9-5-simple-machines).
No numerical force ratio or SI dimension is quoted as an ancient calculation.
Weight includes moving hardware. Rope is massless and inextensible, sheaves
frictionless, motion quasi-static and strands vertical. No timber-frame
geometry, gripping capacity, operator strength, changing drum radius from rope
layers, frictional loss or acceleration is inferred.

## Portable and editable records

A six-field experiment distinguishes rig, tie, controlled-distance kind,
distance, weight and arm ratio. Unknown, incomplete, repeated, off-grid and
oversized input is rejected atomically. JSON duplicate keys are detected after
lexical decoding, including escaped property names. Single-wheel/fixed-tie
states are invalid. Opening a file cannot partially alter controls.

The native HTML save captures state before asynchronous asset loading and
verifies all five scans, both fonts and both license files against SHA-256.
It includes the selected route and its tied-end alternative (where applicable),
windlass, five-route comparison table, all excerpts and contextual notes,
editable JSON, CSV and complete source pages. Its CSP disables scripts and
automatic remote content. Links reopen an explicit online source or state.
The native SVG retains state metadata; the CSV records the selected state,
five task comparisons and 41 slider samples for each route: 211 data rows.
