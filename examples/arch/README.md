# A saved arch experiment

These are actual browser downloads from the reviewed production edition,
not hand-authored expected outputs. The opening arch was repaired by widening
each base while retaining its selected weight, then the whole-model path
finder selected an equilibrium witness. Joint 4 is selected.

| File | Contents |
| --- | --- |
| `experiment.json` | Reopenable settings, including the full non-rounded thrust and bearing contact |
| `contacts.csv` | All fourteen radial contacts, forces, moment constant and pier-base eccentricity |
| `section.svg` | The actual plotted section and joint contact locus; viewer-supplied sans-serif font |
| `reading.html.gz` | Complete script-free illustrated reading with actual pages, fonts, licenses and native downloads |
| `reading.pdf` | Actual 14-page Chromium print of that reading |

```sh
gzip -dc examples/arch/reading.html.gz > /tmp/gonia-arch-reading.html
```

Open the resulting HTML locally. It works without scripts or a connection.
Its online reopening link and external references require a connection.
The [direct review](../../docs/arch-review.md) records the independent artifact
checks and limits. These files describe a modern ideal equilibrium model,
not a measured or certified historical structure.
